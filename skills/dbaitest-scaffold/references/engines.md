# Engines

One test body, three engines. Each engine has its own package, engine class and SQL dialect.

| | SQL Server | PostgreSQL | MySQL |
|---|---|---|---|
| `--engines` name | `mssql` | `postgres` | `mysql` |
| Package | `DbAiTest.MsSql` | `DbAiTest.PostgreSql` | `DbAiTest.MySql` |
| Engine class (`CreateEngine()`) | `new MsSqlEngine()` | `new PostgreSqlEngine()` | `new MySqlEngine()` |
| Namespace | `DbAiTest.MsSql` | `DbAiTest.PostgreSql` | `DbAiTest.MySql` |
| Schema file format | `.sql` | `.sql` / `.psql` | `.sql` |
| Batch separator | `GO` (with `GO n` repeat counts) | none: the whole file is one command | `DELIMITER` |
| Routine body | `CREATE PROCEDURE ... AS BEGIN ... END` | `$$ ... $$` | `BEGIN ... END` inside `DELIMITER //` |
| Identity column | `INT IDENTITY(1,1)` | `INTEGER GENERATED BY DEFAULT AS IDENTITY` | `INT AUTO_INCREMENT` |

## Schema files

- Files under `Schema/<engine>/` are found recursively and applied in order of their relative
  path: number them `001_tables.sql`, `002_procedures.sql`, ...
- `<None Include="Schema\**\*" CopyToOutputDirectory="PreserveNewest" />` in the `.csproj`
  copies them next to the test binaries; `SchemaRoot => "Schema/<engine>"` resolves there.
- The splitters are real scanners: a `GO` or a delimiter inside a string, a quoted identifier or
  a comment is not a separator.
- A schema that only partly applies fails at setup with a `SchemaApplyException` listing every
  broken file. Fix the file it names.

## Writing the same schema three times

Keep table and column names identical across engines so the shared test SQL works everywhere.
Use lower-case `snake_case` names: PostgreSQL folds unquoted names to lower case, and MySQL
table names are case-sensitive on Linux.

## Parameters and results

- Parameters are written `@name` on every engine: `new DbParameterValue("@email", "ada@example.test")`.
- `QueryScalarAsync<T>` absorbs driver differences: `COUNT(*)` is `int` on SQL Server and
  `bigint` elsewhere, and `QueryScalarAsync<int>` works for both. SQL `NULL` or no row gives
  `default`.

## Container options

Override `ContainerOptions` in an engine class to change the image or the database name:

```csharp
protected override DbContainerOptions? ContainerOptions => new() { Image = "postgres:17" };
```

Classes with different options get different containers.
